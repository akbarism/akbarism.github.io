# CV satu halaman

Starter ringan untuk CV personal berbasis Svelte 5, Vite, Tailwind CSS 4, dan Lucide.

## Menjalankan project

```bash
npm install
npm run dev
```

Build produksi:

```bash
npm run build
npm run preview
```

Konten utama berada di `src/App.svelte`, sedangkan style global dan konfigurasi tema Tailwind berada di `src/app.css`.
